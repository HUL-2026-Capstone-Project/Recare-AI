# 평가셋 (초안)

판례 추가 전후 성능을 비교하기 위한 질문 모음입니다. `questions.csv`는 엑셀에서 바로 열 수 있습니다 (UTF-8 BOM).

| 컬럼 | 설명 |
|---|---|
| `id` | 유형 접두어 + 번호 (A 법령형, B 사례형, C 멀티턴, D 범위밖, E 데이터누락) |
| `질문` | 실제 사용자처럼 작성한 질문 |
| `선행질문` | 멀티턴(C) 문항만 해당. 이 id의 질문을 같은 세션에서 먼저 보낸 뒤 질문한다 |
| `정답근거` | 검색되어야 하는 조문. `법령명 제N조` 형식, 여러 개는 `; `로 구분 |
| `핵심포인트` | 답변에 들어가야 할 내용. ` / `로 구분 |
| `비고` | 판례 효과 기대 문항, 데이터 누락 등 메모 |

## 유형별 의도

- **A 법령형 (22)**: 조문을 직접 묻는 질문. 기본 검색 성능을 측정한다.
- **B 사례형 (19)**: 일상적인 말투로 사실관계를 설명하는 질문. 판례를 추가했을 때 가장 크게 좋아질 것으로 예상하는 영역이다 (`비고`에 "판례 효과 기대"로 표시).
- **C 멀티턴 (4)**: 앞 질문의 맥락이 있어야 답할 수 있는 후속 질문.
- **D 범위밖 (4)**: 문서에 없는 내용. 조문을 지어내지 않고 "찾지 못했다"고 안내하는지 확인한다.
- **E 데이터누락 (4)**: 별표 3·6과 요양업무처리규정에 의존하는 질문. 현재는 틀리는 것이 정상이며, 데이터를 보강한 뒤 개선을 확인하는 용도다.

## 주의

- `정답근거`의 조문은 현재 `vector_db/chunks.jsonl`에 실제로 있는지 검증했다. 예외는 별표, 그리고 요양업무처리규정(조문 단위로 잘리지 않아 법령명으로만 매칭됨)이다.
- 초안이므로 법률 판단이 들어간 `핵심포인트`(특히 B04)는 사람이 검토해야 한다.

# 사례 결론 예측 실험

판례를 넣으면 "실제 판결 결과를 더 잘 예측하는가"를 보는 실험입니다.

1. `make_case_holdout.py`: 근로복지공단 1심 판례 중 인정 20건 + 불인정 20건을 뽑아, 판결문의 **'처분의 경위'(사실관계)만으로** 재해자 1인칭 질문을 만듭니다 → `case_holdout.csv`
2. 이 판례들과 그 1·2·3심 연관 판결은 판례 DB에서 빠집니다 (`precedents/build_index.py`). 시스템은 정답 판결을 볼 수 없습니다.
3. `run_case_eval.py`: 질문을 보내고, 답변이 인정/불인정/중립 중 어느 쪽으로 기우는지 GPT-4o로 판정해 실제 결론과 비교합니다.

```bash
python precedents/build_index.py --exclude-holdout                 # 먼저 시험 판례를 뺀 판례 DB로 다시 만든다
PRECEDENT_K=0 python eval/run_case_eval.py --label case_no_prec    # 판례 없이
PRECEDENT_K=3 python eval/run_case_eval.py --label case_with_prec  # 판례 포함
```

| 지표 | 뜻 |
|---|---|
| 정확도 | 예측이 실제 결론과 맞은 비율 (중립은 오답 처리) |
| 판단률 | 중립이 아닌 답을 낸 비율 |
| 판단한 문항 정확도 | 인정/불인정을 말한 문항 중 맞힌 비율 |
| 유출 | 시험 판례(또는 연관 판결)가 검색된 횟수. 0이어야 정상 |

답안 유출을 막기 위해 질문에는 판결의 '처분의 경위' 부분만 쓰고(법원 판단 부분 제외), 항소심·상고심은 처분의 경위가 없어 1심(구단·구합)만 씁니다.

## 결과 (200건, 인정 100 + 불인정 100)

| 실험 | 정확도 | 판단률 | 방향을 정한 답의 정확도 (95% CI) |
|---|---|---|---|
| 판례 없음 | 0.21 | 0.41 | 0.51 (0.40~0.61) |
| 판례 유사순 3건 | 0.27 | 0.54 | 0.49 (0.40~0.58) |
| 판례 균형 4건 | 0.26 | 0.59 | 0.44 (0.35~0.53) |

- 예비 실험(40건, `results/case/pilot40/`)의 0.46 → 0.65 개선은 200건에서 재현되지 않았다.
- 판례를 넣으면 판단을 더 자주 내리지만 정확도는 우연 수준(약 50%)이다.
  판결 결과는 의학적 감정·증거 등 질문(처분의 경위)에 없는 정보로 갈리기 때문으로 보인다.
- 따라서 판례를 근거로 결과를 예측하게 하기보다, 결과를 가른 요소와 준비할 증거를 안내하는 쪽이 안전하다.
