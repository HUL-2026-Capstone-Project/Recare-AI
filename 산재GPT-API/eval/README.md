# 평가셋 (초안)

판례 추가 전후 성능을 비교하기 위한 질문 모음입니다. `questions.csv`는 엑셀에서 바로 열 수 있습니다 (UTF-8 BOM).

| 컬럼 | 설명 |
|---|---|
| `id` | 유형 접두어 + 번호 (A 법령형, B 사례형, C 멀티턴, D 범위밖, E 데이터누락) |
| `질문` | 실제 사용자처럼 작성한 질문 |
| `선행질문` | 멀티턴(C) 문항만 해당. 이 id의 질문을 같은 세션에서 먼저 보낸 뒤 질문한다 |
| `정답근거` | 검색되어야 하는 조문. `법령명 제N조` 형식, 여러 개는 `; `로 구분 |
| `핵심포인트` | 답변에 들어가야 할 내용. ` / `로 구분 |
| `비고` | 판례 효과 기대 문항, 데이터 누락 등 메모 |

## 유형별 의도

- **A 법령형 (22)**: 조문을 직접 묻는 질문. 기본 검색 성능을 측정한다.
- **B 사례형 (19)**: 일상적인 말투로 사실관계를 설명하는 질문. 판례를 추가했을 때 가장 크게 좋아질 것으로 예상하는 영역이다 (`비고`에 "판례 효과 기대"로 표시).
- **C 멀티턴 (4)**: 앞 질문의 맥락이 있어야 답할 수 있는 후속 질문.
- **D 범위밖 (4)**: 문서에 없는 내용. 조문을 지어내지 않고 "찾지 못했다"고 안내하는지 확인한다.
- **E 데이터누락 (4)**: 별표 3·6과 요양업무처리규정에 의존하는 질문. 현재는 틀리는 것이 정상이며, 데이터를 보강한 뒤 개선을 확인하는 용도다.

## 주의

- `정답근거`의 조문은 현재 `vector_db/chunks.jsonl`에 실제로 있는지 검증했다. 예외는 별표, 그리고 요양업무처리규정(조문 단위로 잘리지 않아 법령명으로만 매칭됨)이다.
- 초안이므로 법률 판단이 들어간 `핵심포인트`(특히 B04)는 사람이 검토해야 한다.
